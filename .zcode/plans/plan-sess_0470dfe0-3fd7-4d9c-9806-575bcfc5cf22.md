# Per-Site Strategy Fixer (merged into Auto-Rotation monitor)

## Context

Live user findings: itch.io loads only its title (first GET OK → 6 subsequent GETs die with `NS_BINDING_ABORTED`); works under ALT4/ALT7, fails under ALT2/3/5/6 → **per-site strategy coverage differs per preset**. Desired behavior: probe important sites periodically; when a site breaks, change the strategy **for that site only** and retry; when it loads, go quiet for 5 minutes.

A global preset switch can't do per-site. The correct mechanism is a **winws override profile**: `--hostlist-domains=itch.io` + another preset's strategy args, inserted as the *first* profiles (first match wins) of a generated combined config. So "switch preset for this site" = swap that domain's override profile.

**Decisions** (user-confirmed): merge into the Auto-Rotation monitor (single owner of winws; two watchers would fight over restarts); base preset asked at startup (last choice pre-selected); 15 s re-probe while broken, 5-min quiet after success, escalation ladder — all env-tunable.

**Verified facts enabling this** (from preset inventory):
- All 22 presets: one profile per physical line, ` --new ^` terminators; P1 = QUIC hostlist section (`--filter-udp=443` or EXP's `--filter-l7=quic`, always with the 3 include tokens `list-general.txt`/`list-general-user.txt`/`list-important.txt`), P5 = general TCP hostlist section (`--filter-tcp=80,443` + same includes) — **except ALT5** (6 profiles, no P5; global TCP section `--filter-l3=ipv4 --filter-tcp=80,443,2053,...` without hostlists → fallback source)
- Override conversion recipe: keep the section's filter token + exclude tokens + all `--dpi-desync=...` args verbatim; replace only the 3 `--hostlist="%LISTS%list-*.txt"` include tokens with `--hostlist-domains=<domain>`; treat profile lines as opaque strings (FAKE TLS AUTO contains a batch-escaped `--dpi-desync-fake-tls=^!` that must survive)
- `general (CUSTOM).bat` collides with nothing; `.gitignore` currently lacks an overrides entry
- Monitor integration points: startup block (~line 420), `Invoke-Rotation` (355), main loop (440-520), state functions (140-188), probe pool (255-311), `Start-Preset`/`Stop-Zapret` (345-353), natural-sort enumeration (191)

## Implementation

### 1. Override learning file: `lists/site-overrides.txt`
Lines `domain = StrategyName` (e.g. `itch.io = general (ALT4)`), `#` comments. Learned/persisted by the fixer; add `/lists/site-overrides.txt` to `.gitignore` (user-specific).

### 2. Config generator (new functions in monitor)
`New-CustomConfig(basePresetFile)`:
- Copy base preset preamble (lines 1–15, incl. the 4 `call service.bat` lines) + start line verbatim; add `:: GENERATED by auto-rotation monitor - do not edit` comment
- Then, for each override `domain = strategy`: **TCP override profile** (from strategy's P5 args; ALT5 fallback = its global TCP section args) and **UDP override profile** (from strategy's P1 args, filter token kept verbatim) — includes replaced with `--hostlist-domains=<domain>`, excludes/desync spliced verbatim
- Then the base preset's profile lines verbatim (overridden domains match the earlier profiles; everything else falls through to base sections)
- Write `general (CUSTOM).bat`, CRLF, UTF-8 no BOM, last profile line without caret
- Parser helpers: `Get-PresetSections(file)` → returns P1/P5 arg strings (opaque-string splice, regex only on the 3 exact include tokens)

### 3. Site probe (new scriptblock + runner in monitor)
Per domain, **2 sequential GETs on fresh connections** (~`SITE_GET_GAP=2` s apart): `curl -L -sS -m 12 --connect-timeout 5 -o NUL -w "%{http_code}"` — OK only if **both** exit 0 with a real status (catches the "first GET OK → subsequent killed" signature; mid-body stall exit 28 = FAIL). Same stderr-split idiom as existing probes. Parallel via the existing runspace pool. Env: `SITE_TIMEOUT`, `SITE_CONNECT_TIMEOUT`, `SITE_GET_GAP`.

### 4. Monitor loop extension (the cadence the user asked for)
- State: `monitor state.json` gains `basePreset` + `sites{ domain → {strategy, lastOk, nextCheck, brokenRounds, tried, backoffUntil} }` (extend `Save-State`/`Get-PresetState` with a sibling `Get-SiteState`)
- Startup: refuses service (as today); then **base-preset prompt** (ranked list, default = `basePreset` from state or best-ranked; declining → watch-only mode, per-site fixing disabled with a log note). Generates CUSTOM from base + overrides → starts it → `currentPresetName = "general (CUSTOM)"`. `SITEFIX=0` env disables the whole feature (plain monitor behavior)
- Each loop iteration (existing `MONITOR_INTERVAL=20`): due sites (`nextCheck` passed) get probed:
  - **OK** → `nextCheck = now + 300` s (`SITE_OK_QUIET=300` — the user's 5-min quiet), clear broken state, log only transitions
  - **FAIL** → `brokenRounds++`, next check in `SITE_BROKEN_INTERVAL=15` s; at **2** consecutive broken rounds → **fix cycle**: iterate candidates (all presets except CUSTOM, current-failed strategy skipped, untried first per domain state; max `SITEFIX_MAX_ATTEMPTS=3` per cycle): write/remove override → `New-CustomConfig` → `Stop-Zapret` → `Start-Preset(CUSTOM)` → settle 8 s → site probe. Success → persist override + state, log `itch.io fixed via general (ALT4)`; exhausted → `backoffUntil = now + 600` s (`SITE_BACKOFF`), log
- `Invoke-Rotation` (YouTube stalls, unchanged trigger): after picking the next base, **regenerate CUSTOM from the new base + existing overrides** and start that; `Get-RankedPresets` excludes `general (CUSTOM).bat` (the monitor owns it)
- Env knobs: `SITEFIX`, `SITE_OK_QUIET`, `SITE_BROKEN_INTERVAL`, `SITE_BROKEN_THRESHOLD`, `SITEFIX_MAX_ATTEMPTS`, `SITE_BACKOFF`
